«Оживлению» экрана **DeepCool AK620 Digital Pro**. Проблема в конфликте энергосбережения новых плат (чипсет 800-й серии) и инициализации USB-контроллера кулера.

### 1. Настройки BIOS (Материнская плата ASUS ROG X870E-E)

Чтобы экран не «отваливался» и определялся системой корректно:

 * APM Configuration -> **ErP Ready:** Установить в **[Disabled]**. Это ключевое — плата перестает жестко ограничивать питание портов.

 * Onboard Devices Configuration -> **USB Power Delivery in Soft Off State (S5):** Установить в **[Enabled]**. Питание на USB-колодку кулера будет подаваться постоянно, даже когда ПК выключен или спит.

 * Boot -> ASUS Boot Configuration -> **Fast Boot:** Можно оставить **[Enabled]** для скорости, но если ошибка вернется — переключи  USB Configuration -> **XHCI Hand-off** на **[Enable]**.

 * APM Configuration -> **Restore AC Power Loss:** Установить в **[Power On]**.
 
 *Находясь в BIOS, нажми клавишу F9 (или нажми на иконку лупы в верхней части экрана). Это вызовет строку поиска.

### 2. Настройки Windows 11

Чтобы избежать ошибки «Сбой дескриптора» при выходе из сна:

 * **Быстрый запуск:** Снять галочку в Электропитание (Windows + R, powercfg.cpl) -> Действие кнопок питания. Это заставляет драйверы инициализироваться «чисто» при каждом включении.

 * **Временное отключение USB:**  В Электропитание -> Изменение параметров схемы,  Параметры USB -> Параметр временного отключения USB-порта установить **«Запрещено»**.

 * **Диспетчер устройств:** В разделе «Контроллеры USB» для всех **Корневой USB-концентратор** снять галочку **«Разрешить отключение для экономии энергии»** во вкладке «Управление электропитанием».
