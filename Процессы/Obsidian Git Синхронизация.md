Давайте пошагово разберем, как связать ваш компьютер и телефон с помощью плагина Fit и Git через GitHub.

---

Шаг 1: Подготовка на стороне GitHub

Перед установкой плагина вам нужно подготовить «облако», где будут храниться файлы.

1. Зайдите на **GitHub** и создайте новый **приватный репозиторий** (Private repository). Назовите его, например, `QasrMind`. 
2. Создайте **токен доступа (Personal Access Token)**.
    - Перейдите в _Settings -> Developer Settings -> Personal Access Tokens -> Tokens (classic)_.
    - Нажмите _Generate new token (classic)_.
    - В графе **Note** напишите `Obsidian Fit`.
    - Выберите срок действия (например, 90 дней или _No expiration_, если не хотите обновлять его вручную).
    - **Обязательно** отметьте галочкой пункт **`repo`** (все подпункты внутри него). Это даст плагину доступ к чтению и записи ваших заметок.
    - Нажмите _Generate token_ внизу страницы.
3. **Скопируйте токен и сохраните его в надежном месте!** Как только вы закроете страницу, GitHub больше его не покажет.
4. Добавить файл `.gitignore` с текстом:
    `.obsidian`
	`.trash`

---

Шаг 2: Настройка на компьютере (ПК)

Рекомендуется начинать настройку с устройства, где сейчас находится ваша основная база заметок.

1. Откройте Obsidian на ПК, зайдите в _Настройки -> Сторонние плагины (Community plugins)_.
2. Включите сторонние плагины, нажмите _Обзор (Browse)_, найдите **Fit** и нажмите **Установить (Install)**, а затем **Включить (Enable)**.
3. Зайдите в настройки самого плагина Fit и заполните следующие поля:
    - **GitHub Personal Access Token:** Вставьте скопированный на Шаге 1 токен.
    - **GitHub Repository URL:** Ссылка на ваш созданный репозиторий (например, `https://github.com`).
    - **GitHub Username:** Ваш логин на GitHub.
4. Откройте палитру команд (`Ctrl + P` на Windows или `Cmd + P` на Mac), введите **`Fit: Fit Sync`** и нажмите Enter. Плагин загрузит все ваши текущие заметки с компьютера в репозиторий GitHub.
